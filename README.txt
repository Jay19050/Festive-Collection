FESTIVE COLLECTION WEBSITE

Open index.html in a browser to preview. For best results, use a local static server (for example, VS Code Live Server).

Included:
- Responsive editorial-style storefront
- Product photos extracted from your ZIP
- Product filters and interactive cart
- Bundle pricing calculations
- CAD prices (using $ as supplied)
- Order summary generation

Before publishing:
1. Confirm the temporary product names/photo matching.
2. Add your WhatsApp number in script.js: change const phone='' to country code + number, digits only.
3. Replace RANG·RITUAL with your final brand name.
4. Confirm all prices, product offers, and shipping details.
5. Host the folder on a static hosting provider. Keep index.html, style.css, script.js, and assets together.

This is a front-end catalog/order inquiry site; it does not process payments or store orders on a server.
